# Desktop Canvas

A macOS menu-bar app that turns your Desktop into an ever-changing wallpaper. It reads
what's on your Desktop (file types, clutter, colors, names, recency) and paints a fresh
wallpaper from it, across every display and Space, with smooth transitions.

**[Download the latest version](https://github.com/heynol/desktop-canvas-releases/releases/latest/download/Desktop-Canvas-1.0.0-arm64.dmg)**: open the DMG and drag Desktop Canvas into Applications.

- Requires macOS 14 or later on a Mac with Apple silicon.
- Signed and notarized by Apple. The app updates itself from this page.
- Runs on your Mac. Details about your files only leave it if you pick the AI style and
  add your own OpenAI or Google Gemini key.

This repository only hosts the releases.
